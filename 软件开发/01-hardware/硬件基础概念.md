


# 电流与电压大小场合

<font color=blue>从感性角度理解，在输出功率都是1000W的情况下，电流调大相应的电压就会变小，电流变小电压就会增大，因为总输出功率不变，那么如何形象理解电流和电压？什么时候需要大电流小电压？什么场合需要小电流大电压？
</font>

大电流、小电压（低压大电流）
核心诉求：**近距离传输，需要强大的做功能力（扭矩、热量、驱动能力）**


小电流、大电压（高压小电流）
核心诉求：**长距离传输，优先减少线路损耗；仅需要电场 / 推力，不需要大电流做功**


# 寄生电容

<font color=blue>寄生电容是怎么导致的？
</font>

换句话说，就是两条导体之间即使没有接电容器，也可能因为靠得太近、被绝缘介质隔开而“天然”形成电容。

<font color=blue>如何解决寄生电容问题？或者如果无法彻底解决，那么如何尽量避免或减少寄生电容？
</font>

寄生电容不能完全消除，但可以控制

 **一、芯片级（IC设计）**
1. **缩短互连长度**
    - 金属走线越长，电容越大 → 尽量缩短信号线长度。
    - 在设计布图时，**关键高速信号线要走最短路径**。
2. **减小平行金属面积**
    - 栅极、互连平行过多 → 寄生电容增加。
    - 使用较小的线宽、线间距，减少平行重叠面积。
3. **使用隔离层或空洞**
    - 金属层之间增加介质或空隙，降低互层电容。
    - 在芯片设计中叫做**减少金属层耦合（Metal Coupling）**。
4. **优化晶体管尺寸**
    - 大晶体管栅极会增加 CgsC_{gs}Cgs​ 和 CgdC_{gd}Cgd​ → 尽量合理调整晶体管大小，既保证驱动又不增加过多寄生。


---


**二、PCB/模块设计级**
1. **增大信号与参考地/电源平面的间距**
    - 信号靠近地或电源平面 → 寄生电容大。
    - 关键高速信号保持适当的间距，减少对地电容。
2. **减少平行走线**
    - 高速线尽量不要平行太长 → 避免相互耦合形成寄生电容。
3. **合理选择层叠结构**
    - 对高速板，使用多层 PCB，把高速信号走独立层，隔开电源和地层，降低耦合。
4. **使用阻抗匹配与终端**
    - 虽然不能消除寄生，但匹配阻抗和加终端电阻可以减少寄生电容引起的反射和信号畸变。
5. **去掉不必要的焊盘和过孔**
    - 每个过孔和大焊盘都会增加寄生电容 → 高速信号尽量减少过孔数量。


---


**三、系统/使用级**

1. **减少测试和探针对电路的干扰**
    - 长探针、手靠近 → 寄生电容增加。
    - 使用短探针、缓冲器或示波器探头的低电容模式。
2. **选择合适的驱动能力**
    - 对于寄生电容大的节点，可以使用更强驱动的器件，保证上升/下降时间。
3. **滤波和缓冲策略**
    - 对高速信号，加缓冲或匹配电路，减少寄生电容对逻辑或模拟信号的影响。

---

**四、设计理念总结**

- **“寄生电容不可避免，但可以控制”**
- 原则就是 **缩短长度、减小面积、增加间距、合理布局**。
- 高速电路里，寄生电容直接影响上升沿时间和带宽，需要设计时就考虑。
